## v0.2.1 本轮变更

- 周负责模块：竞赛官方网站链接校验主机名、端口格式及范围，拒绝带登录凭据或空白字符的链接；验证错误更新不会覆盖原链接。
- 王负责模块：队伍创建和列表筛选所用编号限制为 SQLite 正整数范围，超大编号返回输入错误，避免数据库绑定溢出。
- 陈负责模块：电话仅允许数字、普通空格、括号、短横线和开头加号，拒绝内嵌换行、回车及制表符；失败提交不产生报名记录，合法国际格式可提交。

每个模块各增加一个测试方法。2026-11-10 使用 Python unittest 完整发现并运行 32 组测试，耗时 22.510 秒，结果 OK。首次运行被沙箱阻止本机 HTTP 连接，放行本机测试后复验通过；不将环境限制记为业务缺陷。

本轮修改和测试由 Codex 辅助执行，提交按周、王、陈的模块责任边界组织，沿用当前仓库配置的作者。模块分工不作为三人分别独立编码、审查或提交的证明。既有前端、UML、无障碍及其他未提交修改不包含在本轮提交内。
